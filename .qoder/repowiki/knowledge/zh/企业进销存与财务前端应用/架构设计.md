- **技术栈与构建**：采用 Vite 作为构建工具，核心框架为 React 19，UI 组件库使用 Ant Design 6.x，路由管理依赖 React Router DOM 7.x。
- **分层结构**：`src/api/index.js` 封装 Axios 实例，统一处理 Bearer Token 注入及 401 鉴权失效跳转；`src/layouts` 定义 `AdminLayout` 与 `UserLayout` 两种布局容器，通过 `Outlet` 渲染子页面并实现侧边栏导航与移动端抽屉适配。
- **路由与权限**：`App.jsx` 集中配置路由表，利用 `PrivateRoute` 组件拦截未登录访问，并根据用户角色（admin/user）将请求分发至不同的业务模块目录（`pages/admin` 或 `pages/user`）。
- **状态与主题**：全局样式通过 `theme.js` 定制 Ant Design 令牌（Token），实现品牌色统一；业务数据交互遵循“页面组件调用 API -> 更新本地 State -> 渲染 UI”的模式。
